# Benchmark data

These are the files used by the scripts. Rights remain with the original sources; no new licence is given here.

| File | Source | Response and predictors used |
|---|---|---|
| `Auto.csv` | ISLR / UCI Auto MPG | mpg on displacement and weight |
| `insurance.csv` | Medical Cost Personal Dataset (Lantz, teaching-data mirror) | charges on age and BMI |
| `Hitters.csv` | ISLR Hitters | Salary on hits and home runs; rows with missing values removed by the loader |
| `engel.csv` | R package quantreg, Engel data | food expenditure on income |
| `abalone.csv` | UCI Abalone (Nash et al., 1994) | rings on seven physical measurements (sex not included) |
